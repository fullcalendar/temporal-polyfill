# Temporal Monorepo

A collection of packages for working with [Temporal](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal), the modern successor to the JavaScript `Date` object. 🕒

## Packages

- 📦 **[temporal-polyfill](./polyfill/README.md)** — A lightweight, spec-compliant polyfill for Temporal
  - 🌳 [Tree-shakeable function-based API docs](./docs/fns/index.md)
- 🔄 **[temporal-polyfill-codemod](./codemod/README.md)** — Codemods for migrating `temporal-polyfill` code
- 🛠️ **[temporal-utils](./utils/README.md)** — Handy utilities for Temporal objects
- 📐 **[temporal-spec](./spec/README.md)** — Standalone TypeScript type definitions for Temporal
